# نظرة عامة على المشروع (Project Overview)

هذا المشروع هو نظام إدارة شامل مصمم لتسهيل إدارة المعلومات المتعلقة بالطلاب، المعلمين، المجموعات الدراسية، الحضور، والمدفوعات. يهدف المشروع إلى توفير واجهة سهلة الاستخدام لإدارة هذه الجوانب المختلفة بكفاءة.

## الميزات الرئيسية (Main Features)

*   **إدارة الطلاب:** إضافة، عرض، تعديل، وحذف بيانات الطلاب.
*   **إدارة المعلمين:** إضافة، عرض، تعديل، وحذف بيانات المعلمين.
*   **إدارة المجموعات الدراسية:** إنشاء مجموعات دراسية، تحديد المعلمين لها، وإضافة الطلاب إليها.
*   **نظام الحضور:** تسجيل حضور وغياب الطلاب في الجلسات المختلفة.
*   **إدارة المدفوعات:** تتبع مدفوعات الطلاب وإدارة السجلات المالية.
*   **تقارير مالية:** عرض ملخصات وتقارير عن الإيرادات والمصروفات.

# إعداد الواجهة الأمامية (Frontend Setup)

لتشغيل الواجهة الأمامية للمشروع على جهازك، يرجى اتباع الخطوات التالية. هذه التعليمات تفترض أنك لا تملك خبرة مسبقة مع React أو الأدوات المستخدمة.

## المتطلبات الأساسية (Prerequisites)

قبل البدء، تأكد من أن لديك البرامج التالية مثبتة على جهازك:

1.  **Node.js:** هي بيئة تشغيل JavaScript. يمكنك تحميلها وتثبيتها من [الموقع الرسمي لـ Node.js](https://nodejs.org/). عند تثبيت Node.js, سيتم تثبيت `npm` (مدير حزم Node) تلقائيًا، وهو أداة لإدارة مكتبات المشروع.
    *   للتحقق من تثبيت Node.js و npm، افتح الطرفية (Terminal أو Command Prompt) واكتب الأوامر التالية:
        ```bash
        node -v
        npm -v
        ```
        يجب أن يعرض كل أمر رقم الإصدار المثبت.

2.  **Bun (اختياري ولكن موصى به):** هو أداة أحدث وأسرع لتشغيل مشاريع JavaScript. إذا كنت ترغب في استخدامه، يمكنك تثبيته من [الموقع الرسمي لـ Bun](https://bun.sh/). المشروع يدعم `npm` و `bun`.

## خطوات الإعداد (Setup Steps)

1.  **الانتقال إلى مجلد المشروع:**
    *   افتح الطرفية (Terminal).
    *   استخدم الأمر `cd` للانتقال إلى المجلد الرئيسي للمشروع حيث قمت بتنزيله أو نسخه. على سبيل المثال:
        ```bash
        cd path/to/your/project-directory # استبدل هذا بالمسار الفعلي لمجلد المشروع على جهازك
        ```

2.  **تثبيت الاعتماديات (Install Dependencies):**
    *   الاعتماديات هي مكتبات وأدوات إضافية يحتاجها المشروع ليعمل بشكل صحيح.
    *   إذا كنت تستخدم `npm` (الذي يأتي مع Node.js)، قم بتشغيل الأمر التالي في الطرفية من المجلد الرئيسي للمشروع:
        ```bash
        npm install
        ```
    *   إذا كنت تفضل استخدام `bun`، قم بتشغيل الأمر التالي:
        ```bash
        bun install
        ```
    *   سيقوم هذا الأمر بقراءة ملف `package.json` وتنزيل جميع المكتبات المطلوبة.

3.  **تشغيل خادم التطوير للواجهة الأمامية (Run Frontend Development Server):**
    *   بعد تثبيت الاعتماديات بنجاح، يمكنك تشغيل الواجهة الأمامية.
    *   إذا كنت تستخدم `npm`، قم بتشغيل الأمر التالي:
        ```bash
        npm run dev
        ```
    *   إذا كنت تستخدم `bun`، قم بتشغيل الأمر التالي:
        ```bash
        bun run dev
        ```
    *   سيقوم هذا الأمر بتشغيل خادم تطوير محلي (عادة على العنوان `http://localhost:5173` أو عنوان مشابه). سيتم عرض العنوان الدقيق في الطرفية.
    *   افتح متصفح الويب الخاص بك وانتقل إلى هذا العنوان لرؤية الواجهة الأمامية للمشروع. أي تغييرات تجريها على أكواد الواجهة الأمامية ستظهر تلقائيًا في المتصفح.

# إعداد الواجهة الخلفية (Backend Setup)

الواجهة الخلفية هي المسؤولة عن التعامل مع قاعدة البيانات ومنطق الأعمال للمشروع. اتبع هذه الخطوات لإعدادها:

## المتطلبات الأساسية (Prerequisites)

1.  **Node.js و npm:** كما هو مذكور في قسم الواجهة الأمامية، تأكد من تثبيت Node.js و npm. الواجهة الخلفية تستخدم `npm` لإدارة الاعتماديات.

## خطوات الإعداد (Setup Steps)

1.  **الانتقال إلى مجلد الواجهة الخلفية:**
    *   الواجهة الخلفية موجودة في مجلد منفصل يسمى `backend` داخل مجلد المشروع الرئيسي.
    *   افتح طرفية جديدة أو استخدم نفس الطرفية، وتأكد أنك في المجلد الرئيسي للمشروع. ثم انتقل إلى مجلد `backend` باستخدام الأمر:
        ```bash
        cd backend
        ```

2.  **تثبيت اعتماديات الواجهة الخلفية (Install Backend Dependencies):**
    *   الواجهة الخلفية لها اعتمادياتها الخاصة المدرجة في ملف `backend/package.json`.
    *   لتثبيتها، قم بتشغيل الأمر التالي وأنت داخل مجلد `backend`:
        ```bash
        npm install
        ```

3.  **تشغيل خادم الواجهة الخلفية (Run Backend Server):**
    *   بعد تثبيت الاعتماديات، يمكنك تشغيل خادم الواجهة الخلفية.
    *   لتشغيل الخادم في وضع التطوير (development mode)، استخدم الأمر التالي وأنت داخل مجلد `backend`:
        ```bash
        npm run dev
        ```
    *   سيقوم هذا الأمر بتشغيل الخادم (عادة على العنوان `http://localhost:3001`). سيعرض الخادم رسالة في الطرفية تؤكد أنه يعمل.
    *   هذا الخادم سيتعامل مع الطلبات من الواجهة الأمامية ويتفاعل مع قاعدة البيانات.

# إعداد قاعدة البيانات (Database Setup)

يستخدم المشروع Prisma كأداة للتعامل مع قاعدة البيانات (ORM)، وقاعدة بيانات SQLite كخيار افتراضي للتطوير. SQLite هي قاعدة بيانات قائمة على ملف واحد ولا تتطلب تثبيت خادم منفصل.

## خطوات الإعداد (Setup Steps)

1.  **فهم Prisma و SQLite:**
    *   **Prisma:** هي أداة تساعد المطورين على التفاعل مع قاعدة البيانات بسهولة أكبر باستخدام JavaScript أو TypeScript. تقوم بتعريف هيكل قاعدة البيانات (يسمى schema) في ملف `backend/prisma/schema.prisma`.
    *   **SQLite:** هي قاعدة بيانات خفيفة الوزن تخزن البيانات في ملف واحد. في هذا المشروع، ملف قاعدة البيانات الافتراضي هو `dev.db` ويقع في `backend/prisma/`.

2.  **تهيئة قاعدة البيانات وتطبيق الترحيلات (Initialize Database and Apply Migrations):**
    *   "الترحيلات" (Migrations) هي طريقة لتحديث هيكل قاعدة البيانات بشكل تدريجي ومنظم. عندما يتم تعريف أو تعديل هيكل قاعدة البيانات في `schema.prisma`, يجب تطبيق هذه التغييرات على قاعدة البيانات الفعلية.
    *   يجب أن تكون في مجلد الواجهة الخلفية (`backend`) لتنفيذ أوامر Prisma. إذا لم تكن هناك، انتقل إليه:
        ```bash
        cd path/to/your/project-directory/backend # استبدل هذا بالمسار الفعلي لمجلد الواجهة الخلفية
        ```
    *   لتطبيق أي ترحيلات موجودة وإنشاء قاعدة البيانات إذا لم تكن موجودة، قم بتشغيل الأمر التالي:
        ```bash
        npx prisma migrate dev --name init
        ```
        *   `npx` هو أداة تأتي مع `npm` لتشغيل حزم Node.
        *   `prisma migrate dev` هو الأمر الذي يطبق الترحيلات.
        *   `--name init` هو اسم وصفي للترحيل (يمكن أن يكون أي اسم إذا كنت تنشئ ترحيلاً جديداً, ولكن `init` مناسب لأول مرة).
    *   سيقوم هذا الأمر بـ:
        *   إنشاء ملف قاعدة البيانات `dev.db` في `backend/prisma/` إذا لم يكن موجوداً.
        *   تطبيق التغييرات المحددة في ملف `schema.prisma` على قاعدة البيانات.
        *   إنشاء Prisma Client، وهو كود يمكنك استخدامه في الواجهة الخلفية للتفاعل مع قاعدة البيانات.

3.  **التأكد من الاتصال بقاعدة البيانات:**
    *   يتم تعريف متغير البيئة `DATABASE_URL` في ملف يسمى `.env` داخل مجلد `backend`. إذا لم يكن هذا الملف موجودًا، قد تحتاج لإنشائه. أحيانًا، يوفر المبرمجون ملفًا باسم `.env.example` كقالب يمكنك نسخه وتسميته `.env`. هذا المتغير يخبر Prisma بمكان ملف قاعدة البيانات. افتراضيًا، يشير إلى:
        `DATABASE_URL="file:./dev.db"`
        وهذا يعني أن ملف قاعدة البيانات `dev.db` موجود في نفس مجلد `prisma`.
    *   عند تشغيل خادم الواجهة الخلفية (`npm run dev` في مجلد `backend`), يجب أن يتصل تلقائيًا بقاعدة البيانات.

بهذه الخطوات، تكون قاعدة البيانات جاهزة للاستخدام مع الواجهة الخلفية.

# كيفية استخدام المشروع (Project Usage)

بعد إعداد وتشغيل كل من الواجهة الأمامية والخلفية بنجاح، يمكنك البدء في استخدام النظام.

1.  **الوصول إلى التطبيق:**
    *   افتح متصفح الويب الخاص بك وانتقل إلى عنوان الواجهة الأمامية الذي ظهر عند تشغيل الأمر `npm run dev` (عادة `http://localhost:5173`).

2.  **استكشاف الواجهة:**
    *   ستجد قائمة جانبية أو شريط تنقل يحتوي على الأقسام الرئيسية للنظام.
    *   **لوحة التحكم الرئيسية (Dashboard):** قد تعرض ملخصًا عامًا للبيانات.
    *   **إدارة الطلاب (Students Management):** من هنا يمكنك إضافة طلاب جدد، عرض قائمة الطلاب الحاليين، تعديل بياناتهم، أو حذفهم.
    *   **إدارة المعلمين (Teachers Management):** لإدارة بيانات المعلمين بنفس الطريقة.
    *   **إدارة المجموعات (Groups Management):** لإنشاء مجموعات دراسية، ربطها بمعلمين، وتسجيل الطلاب فيها.
    *   **نظام الحضور (Attendance System):** لتسجيل حضور الطلاب في الجلسات الدراسية المختلفة لكل مجموعة.
    *   **إدارة المدفوعات (Payments Management):** لتتبع الاشتراكات والمدفوعات الخاصة بالطلاب.
    *   **السجلات المالية (Financial Records):** لإدارة وتتبع الإيرادات والمصروفات العامة للمؤسسة.

3.  **التفاعل مع النماذج والجداول:**
    *   ستستخدم نماذج (forms) لإدخال البيانات الجديدة (مثل إضافة طالب جديد).
    *   سيتم عرض البيانات في جداول (tables) يمكنك من خلالها فرز البيانات أو البحث فيها.

يهدف التصميم إلى أن يكون بديهيًا وسهل الاستخدام. قم باستكشاف الأقسام المختلفة للتعرف على جميع الميزات.
