# مرحبًا بك في مشروعك الجديد لإدارة المؤسسات التعليمية (ترجمة للعربية)

## عن المشروع

هذا المشروع هو تطبيق ويب حديث مبني باستخدام React و TypeScript، مصمم لمساعدة المؤسسات التعليمية (مثل المدارس أو مراكز التدريب) في إدارة جوانب متعددة من عملياتها اليومية. يهدف إلى توفير واجهة سهلة الاستخدام لتسهيل المهام الإدارية والأكاديمية.

**التقنيات المستخدمة:**

*   **Vite:** أداة بناء سريعة لتطبيقات الويب الحديثة.
*   **React:** مكتبة JavaScript لإنشاء واجهات المستخدم.
*   **TypeScript:** لغة برمجة تضيف أنواعًا ثابتة إلى JavaScript لتحسين قابلية الصيانة.
*   **shadcn-ui:** مجموعة من مكونات واجهة المستخدم الجميلة والقابلة لإعادة الاستخدام.
*   **Tailwind CSS:** إطار عمل CSS لتصميم سريع ومخصص.

## كيفية إعداد وتشغيل المشروع محليًا

لتشغيل هذا المشروع على جهازك، ستحتاج إلى تثبيت Node.js و npm (مدير حزم Node.js). إذا لم تكن قد قمت بتثبيتهما بعد، اتبع الخطوات التالية:

1.  **تثبيت Node.js و npm:**
    *   الطريقة الموصى بها هي استخدام `nvm` (Node Version Manager). يمكنك العثور على تعليمات التثبيت هنا: [تثبيت nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
    *   بعد تثبيت nvm، قم بتثبيت أحدث إصدار مستقر من Node.js (والذي يتضمن npm) باستخدام الأمر:
        ```bash
        nvm install --lts
        nvm use --lts
        ```
    *   للتحقق من التثبيت، افتح الطرفية (Terminal أو Command Prompt) واكتب:
        ```bash
        node -v
        npm -v
        ```
        يجب أن ترى أرقام الإصدارات الخاصة بهما.

2.  **استنساخ (تحميل) المشروع:**
    *   إذا كان لديك رابط Git للمشروع، استخدم الأمر التالي في الطرفية (استبدل `<YOUR_GIT_URL>` بالرابط الفعلي):
        ```bash
        git clone <YOUR_GIT_URL>
        ```
    *   انتقل إلى مجلد المشروع:
        ```bash
        cd <اسم_مجلد_المشروع>
        ```
    *   إذا قمت بتنزيل المشروع كملف مضغوط (ZIP)، قم بفك ضغطه ثم انتقل إلى المجلد الناتج عبر الطرفية.

3.  **تثبيت الاعتماديات (Dependencies):**
    *   بمجرد دخولك إلى مجلد المشروع عبر الطرفية، قم بتشغيل الأمر التالي لتثبيت جميع الحزم والمكتبات التي يعتمد عليها المشروع:
        ```bash
        npm install
        # أو إذا كنت تفضل استخدام yarn:
        # yarn install
        ```

4.  **تشغيل خادم التطوير:**
    *   بعد اكتمال تثبيت الاعتماديات، قم بتشغيل الأمر التالي لبدء خادم التطوير المحلي:
        ```bash
        npm run dev
        # أو إذا كنت تفضل استخدام yarn:
        # yarn dev
        ```
    *   سيقوم هذا الأمر بتشغيل التطبيق (عادةً على العنوان `http://localhost:5173` أو عنوان مشابه). سيتم عرض الرابط في الطرفية.
    *   افتح هذا الرابط في متصفح الويب الخاص بك لترى التطبيق قيد التشغيل. سيتم تحديث التطبيق تلقائيًا في المتصفح كلما قمت بحفظ تغييرات في الشيفرة المصدرية.

## حالة قاعدة البيانات الحالية وإرشادات التكامل

**الوضع الحالي:**

حاليًا، هذا المشروع **لا يتضمن تكاملاً مباشرًا مع قاعدة بيانات تقليدية** (مثل SQL Server, PostgreSQL, MySQL). قد يعتمد المشروع على:

*   **بيانات ثابتة (Static Data):** بيانات مدمجة مباشرة في الشيفرة (مثل الملف `src/data/academicData.ts` الذي يحتوي على المستويات والمواد الدراسية).
*   **تخزين من جانب العميل (Client-side Storage):** استخدام تقنيات مثل `localStorage` أو `sessionStorage` في المتصفح لتخزين بعض البيانات مؤقتًا. هذا النوع من التخزين محدود وغير مناسب للبيانات الكبيرة أو الحساسة أو التي تحتاج إلى مشاركة بين عدة مستخدمين.

**لماذا نحتاج إلى قاعدة بيانات؟**

لتخزين البيانات بشكل دائم وآمن وفعال (مثل معلومات الطلاب، المدرسين، الجداول الدراسية، المدفوعات، إلخ)، ستحتاج إلى ربط المشروع بقاعدة بيانات من خلال واجهة خلفية (Backend API).

**خطوات عامة لربط قاعدة بيانات (للمطورين):**

إذا كنت ترغب في إضافة قاعدة بيانات إلى هذا المشروع، فإليك الخطوات العامة التي يمكنك اتباعها. هذه عملية متقدمة تتطلب معرفة بتطوير الواجهات الخلفية وقواعد البيانات.

1.  **اختيار قاعدة بيانات:**
    *   **SQLite:** خيار جيد للبداية والمشاريع الصغيرة لأنه قائم على الملفات ولا يتطلب خادمًا منفصلاً.
    *   **PostgreSQL:** قاعدة بيانات علائقية مفتوحة المصدر قوية ومتقدمة.
    *   **MySQL:** قاعدة بيانات علائقية مفتوحة المصدر شائعة جدًا.
    *   **MongoDB:** قاعدة بيانات NoSQL موجهة للمستندات، مرنة وقابلة للتوسع.
    *   يعتمد الاختيار على متطلبات مشروعك وحجم البيانات المتوقع.

2.  **إعداد الواجهة الخلفية (Backend API):**
    *   ستحتاج إلى إنشاء تطبيق خلفي يعمل كجسر بين واجهة React الأمامية وقاعدة البيانات.
    *   **لغات وأطر عمل شائعة للواجهة الخلفية:**
        *   **Node.js مع Express.js:** خيار شائع لمطوري JavaScript/TypeScript.
        *   **Python مع Django أو Flask:** خيارات قوية ومرنة.
        *   **Java مع Spring Boot:** مناسب للتطبيقات الكبيرة والمعقدة.
        *   **Ruby مع Ruby on Rails:** يركز على الإنتاجية وسرعة التطوير.
    *   سيقوم هذا التطبيق الخلفي بتعريف "نقاط نهاية" (API Endpoints) - وهي عناوين URL محددة يمكن لتطبيق React الأمامي إرسال طلبات إليها (مثل طلب قائمة الطلاب أو إضافة طالب جديد).

3.  **تثبيت وإعداد قاعدة البيانات المختارة:**
    *   قم بتثبيت برنامج قاعدة البيانات على جهازك أو استخدم خدمة قاعدة بيانات مستضافة (Cloud Database).
    *   قم بإنشاء قاعدة بيانات جديدة وجداول لتخزين بياناتك (مثل جدول للطلاب، جدول للمجموعات، إلخ).

4.  **ربط الواجهة الخلفية بقاعدة البيانات:**
    *   استخدم "موصل" (Connector) أو "مكتبة" (Library) خاصة بقاعدة البيانات في لغة الواجهة الخلفية التي اخترتها للاتصال بقاعدة البيانات وتنفيذ الاستعلامات (Queries).
    *   **ORM (Object-Relational Mapper):** أدوات مثل Prisma (لـ Node.js/TypeScript) أو SQLAlchemy (لـ Python) أو TypeORM (لـ Node.js/TypeScript) يمكن أن تسهل التفاعل مع قاعدة البيانات عن طريق تحويل الكائنات في الشيفرة إلى سجلات في قاعدة البيانات والعكس.

5.  **إنشاء وظائف CRUD في الواجهة الخلفية:**
    *   لكل نوع من البيانات (طلاب، مدرسين، إلخ)، قم بإنشاء وظائف في الواجهة الخلفية للقيام بالعمليات الأساسية:
        *   **C**reate (إنشاء): إضافة سجل جديد.
        *   **R**ead (قراءة): جلب السجلات.
        *   **U**pdate (تحديث): تعديل سجل موجود.
        *   **D**elete (حذف): إزالة سجل.
    *   اجعل هذه الوظائف متاحة عبر نقاط نهاية الـ API.

6.  **تعديل تطبيق React الأمامي:**
    *   بدلاً من استخدام البيانات الثابتة أو `localStorage`، قم بتعديل مكونات React لإجراء طلبات (HTTP requests) إلى نقاط نهاية الـ API التي أنشأتها في الواجهة الخلفية.
    *   استخدم مكتبات مثل `axios` أو `fetch` API المدمجة في المتصفح لإرسال هذه الطلبات.
    *   عندما تحتاج إلى عرض بيانات، قم بجلبها من الـ API.
    *   عندما يقوم المستخدم بإجراء تغيير (مثل إضافة طالب)، أرسل البيانات إلى الـ API ليتم حفظها في قاعدة البيانات.

**مثال بسيط (تصوري):**

*   **الواجهة الأمامية (React):** عندما يفتح المستخدم صفحة "قائمة الطلاب"، يقوم React بإرسال طلب GET إلى `http://localhost:3001/api/students` (إذا كان الخادم الخلفي يعمل على المنفذ 3001).
*   **الواجهة الخلفية (Node.js/Express):** يستقبل الطلب، يتصل بقاعدة البيانات، يجلب قائمة الطلاب، ثم يرسلها مرة أخرى إلى React كبيانات JSON.
*   **الواجهة الأمامية (React):** يستقبل البيانات ويعرضها للمستخدم.

**ملاحظة:** هذه مجرد إرشادات عامة. عملية تكامل قاعدة البيانات هي مهمة تطوير كبيرة تتطلب تخطيطًا دقيقًا ومعرفة تقنية. إذا كنت جديدًا في هذا المجال، فمن المستحسن البدء بمشاريع تعليمية أصغر لفهم المفاهيم الأساسية أولاً.
